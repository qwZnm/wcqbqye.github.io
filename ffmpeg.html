单线程内核说明

本页使用纯单线程版 @ffmpeg/core-st@0.11.1，不依赖 pthread，不需要 SharedArrayBuffer，也不需要 COOP/COEP 等特殊 HTTP 响应头，适合直接部署到 GitHub Pages。

代价是处理速度比多线程版慢一些，但音频剪切、音频转格式、小视频剪切等任务完全够用。WASM 内存通常约 1-2GB，已设置 500MB 文件保护阈值，过大文件会直接拦截。
