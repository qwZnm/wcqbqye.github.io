⚙️ 技术实现
本工具通过 Bilibili 官方 API 获取视频信息和播放地址：
1. 调用 /x/web-interface/view 获取视频信息和 cid
2. 调用 https://api.bilibili.com/x/player/playurl 获取 DASH 音视频流地址
3. GitHub Pages 与 api.bilibili.com 不同源，浏览器会拦截直接 fetch 响应，因此必须通过代理服务转发请求
4. 项目已附带 cloudflare-worker.js，可部署为自己的 CORS 代理
5. B站视频采用 DASH 协议，音视频分离存储为 .m4s 文件
